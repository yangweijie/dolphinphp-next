# KRix - ThinkPHP 8 + Thinkrix Admin Panel 项目

## 概述

KRix 是一个基于 **ThinkPHP 8** 框架和 **lartrix/thinkrix** 管理后台包构建的 PHP Web 应用项目。它开箱即用地集成了完整的现代化管理后台前端（Vue 3 + Vite 构建），提供 RBAC 权限管理、菜单管理、系统设置、通知中心等企业级功能。

## 添加自定义页面

在 thinkrix 中添加自定义页面需要三步：**路由 → 控制器 → 菜单注册**。

### URL 格式规则

> ⚠️ **关键**：`admin_menus` 表的 `schema_source` 字段是**相对路径**（带前导斜杠），前端会自动拼接 `baseURL`（默认 `/api/admin`）。

```
schema_source: /page-config/schema
baseURL:       /api/admin
前端拼接结果:   /api/admin/page-config/schema  ✅
```

❌ 常见错误：`schema_source` 写成 `/api/admin/page-config/schema` → 前端拼接后变成 `/api/admin/api/admin/page-config/schema`（重复前缀）。

### 第一步：定义路由

在 `route/app.php` 中添加 API 路由：

```php
use think\facade\Route;
use app\middleware\Authenticate;

Route::group('api/admin', function () {
    // 路由路径对应 schema_source 的路径部分
    Route::get('page-config/schema', 'app\\controller\\admin\\PageConfig@schema');
})->middleware(Authenticate::class);
```

### 第二步：创建控制器

控制器返回 `success($schema->toArray())` 即可（与 HomeController 一致）：

```php
<?php
namespace app\controller\admin;

use app\BaseController;
use thinkrix\schema\Builder;

class PageConfig extends BaseController
{
    public function schema()
    {
        $schema = Builder::Flex()
            ->children([
                // ... 组件结构
            ]);

        return $this->success($schema->toArray());
    }
}
```

### 第三步：注册菜单

在 `admin_menus` 表中插入记录：

```sql
INSERT INTO admin_menus (
    id, name, path, title, icon, schema_source,
    parent_id, `order`, requires_auth, is_visible
) VALUES (
    10, 'page_config', '/page-config', '页面配置', 'carbon:page-edit',
    '/page-config/schema', 0, 100, 1, 1
);
```

字段说明：

| 字段 | 值 | 说明 |
|------|-----|------|
| `path` | `/page-config` | 前端路由路径（SPA 内部路由） |
| `schema_source` | `/page-config/schema` | API 端点（相对路径，**必须带前导斜杠**） |
| `parent_id` | `0` | 顶级菜单 |
| `requires_auth` | `1` | 需要登录 |
| `is_visible` | `1` | 在侧边栏显示 |

### 前端渲染流程

```
1. 用户点击侧边栏菜单 "页面配置"
   ↓
2. 前端路由跳转到 /page-config
   ↓
3. DynamicPage 组件读取菜单 meta.schemaSource = "/page-config/schema"
   ↓
4. 发起 GET /api/admin/page-config/schema（baseURL + schemaSource）
   ↓
5. Thinkrix 路由匹配 → PageConfig::schema() 执行
   ↓
6. 返回 JSON schema → 前端渲染组件
```

### 带查询参数的页面

对于带 action_type 的页面（如 CRUD 列表），`schema_source` 格式：

```sql
-- schema_source 带查询参数
'/users?action_type=list_ui'
```

控制器中通过 `request()->get('action_type')` 读取参数，根据不同 action_type 返回不同 schema。

### 带权限的页面

在 `admin_permissions` 表注册权限，再关联到菜单：

```sql
-- 1. 注册权限
INSERT INTO admin_permissions (id, name, display_name, `group`)
VALUES (10, 'admin.page_config', '页面配置', '页面');

-- 2. 菜单关联权限（通过 admin_menu_permissions 中间表）
INSERT INTO admin_menu_permissions (menu_id, permission_id) VALUES (10, 10);
```

控制器中可通过 `auth()->check('admin.page_config')` 检查权限。

#### 完整 CRUD 控制器（推荐模式）

推荐在控制器中使用 `schema()` 方法返回 Schema 数组给前端渲染：

```php
<?php
namespace app\controller\admin;

use Thinkrix\Schema\Components\NaiveUI\Tag;

use Thinkrix\Schema\Components\NaiveUI\Select;
use Thinkrix\Schema\Components\NaiveUI\SwitchC;

class User extends BaseController
{
    public function schema(): array
    {
        return CrudPage::make('用户管理')
            ->apiPrefix('/api/admin/user')
            ->rowKey('id')
            ->search([
                ['用户名', 'keyword', Input::make()->props(['placeholder' => '用户名', 'clearable' => true])],
                ['状态',   'status',  Select::make()->props([
                    'options' => [['label' => '启用', 'value' => 1], ['label' => '禁用', 'value' => 0]],
                    'clearable' => true,
                ])],
            ])
            ->toolbarLeft(['columnSelector', 'batchDelete', 'exportCurrent', 'exportAll'])
            ->toolbarRight([Button::make()->type('primary')->text('新增')])
            ->columns([
                ['key' => 'id',        'title' => 'ID',     'width' => 70,  'fixed' => 'left'],
                ['key' => 'username',  'title' => '用户名', 'width' => 120, 'fixed' => 'left'],
                ['key' => 'nickname',  'title' => '昵称',   'width' => 120],
                ['key' => 'email',     'title' => '邮箱',   'width' => 200],
                ['key' => 'mobile',    'title' => '手机号', 'width' => 130],
                ['key' => 'status',    'title' => '状态',   'width' => 90,
                    'slot' => [
                        Tag::make()->props(['type' => '{{ slotData.row.status === 1 ? "success" : "error" }}'])
                            ->text('{{ slotData.row.status === 1 ? "启用" : "禁用" }}'),
                    ]],
                ['key' => 'role_name', 'title' => '角色',   'width' => 120,
                    'slot' => [Tag::make()->type('primary')->text('{{ slotData.row.role_name }}')]],
                ['key' => 'created_at', 'title' => '创建时间', 'width' => 170],
                ['key' => 'actions',  'title' => '操作',    'width' => 200, 'fixed' => 'right',
                    'slot' => [
                        Button::make()->type('primary')->size('small')
                            ->on('click', SetAction::make('editVisible', true))->text('编辑'),
                        Button::make()->type('error')->size('small')
                            ->on('click', CallAction::make('handleDelete', ['{{ slotData.row.id }}']))->text('删除'),
                    ]],
            ])
            ->build();
    }

    public function list(): \think\Response
    {
        $page     = $this->request->param('page', 1, 'intval');
        $pageSize = $this->request->param('page_size', 15, 'intval');
        $keyword  = $this->request->param('keyword', '');
        $status   = $this->request->param('status', '');

        $query = \app\model\AdminUser::with(['role']);

        if ($keyword) $query->where('username|nickname|email', 'like', "%{$keyword}%");
        if ($status !== '') $query->where('status', $status);

        $total = $query->count();
        $list  = $query->order('id', 'desc')->page($page, $pageSize)->select()
            ->each(fn($item) => $item->visible(['role_name' => $item->role?->name]));

        return json(['code' => 0, 'data' => ['list' => $list, 'total' => $total]]);
    }

    public function save(): \think\Response
    {
        $data = $this->request->post();
        // 验证... 然后 \app\model\AdminUser::create($data);
        return json(['code' => 0, 'msg' => '保存成功']);
    }
}
```

## 常见问题

### Q: 安装后访问后台 404

确保运行了迁移命令：`php think migrate:run`，并确认 `.env` 中数据库配置正确。

### Q: 如何修改后台路径

修改 `.env` 中的 `THINKRIX_PATH` 值，默认 `/admin`。

### Q: 如何使用 SQLite 替代 MySQL

修改 `.env`：
```ini
DB_TYPE = sqlite
# 注释掉 MySQL 相关配置，取消 SQLite 配置注释
```

注意：thinkrix 对 SQLite 的支持有限，建议使用 MySQL。

### Q: 提示 "Class 'app\controller\Xxx' not found"

检查控制器类的命名空间和文件路径是否匹配 PSR-4 规范。如果使用了模块目录（`Modules/`），确认 `composer.json` 的自动加载配置已包含该路径。

### Q: 如何自定义主题

在数据库中的系统设置管理后台，或通过 `config/thinkrix.php` 的 `theme` 配置项进行默认值设置。在前端页面可以直接在主题设置面板中实时调整。
